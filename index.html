Interview Questions

1. Native App vs Progressive Web App

  • Native App → Installed from Play Store/App Store.
  • PWA → Website behaves like mobile app.

2. Difference Between var, let and const

var a = 10;
let b = 20;
const c = 30;
  • var → redeclare and reassign allowed.
  • let → reassign allowed but redeclare not allowed.
  • const → neither redeclare nor reassign allowed.

3. Reassignment vs Redeclaration

let x = 10;
x = 20;

let y = 30;
let y = 40;
  • Reassignment means changing value.
  • Redeclaration means creating same variable again.

4. prompt() and alert()

  • prompt() returns string value.
  • Use Number() or parseInt() for conversion.

5. Object vs Array

  • Multiple datatype → Object {}
  • Same datatype → Array []

6. What is Dot Notation?

console.log(obj.name)
  • Used to access object properties.

7. Array is also an Object

console.log(typeof arr)
  • Array contains key(index) and value(element).
