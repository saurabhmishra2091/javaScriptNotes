Reverse Loop in Array

for(let i = arr.length; i >= 0; i--){
   console.log(arr[i])
}

// Output:
// undefined 5 4 3 2 1
  • Array index starts from 0.
  • arr.length gives one extra position.
  • That's why first output becomes undefined.

for...of Loop

const arr = [1,2,3,4,5]

for(let i of arr){
   console.log(i)
}
  • for...of loop gives values/elements directly.
  • Mostly used with arrays and strings.
const arr = ['apple','ball','cat']

for(let i of arr){
   console.log(arr[i])
}

// Output:
// undefined undefined undefined
  • In for...of loop, i already contains value.
  • Here i = "apple", "ball", "cat"
  • arr["apple"] does not exist, so output becomes undefined.

for...in Loop

const arr = ['apple','ball','cat']

for(let i in arr){

   console.log(`Hi, my index is ${i} and my value is ${arr[i]}`)

}
  • for...in loop gives index/key.
  • Mostly used for objects.
  • Template literals use backticks ` `.

forEach Method

const arr = [1,2,3,4,5]

arr.forEach((a,i)=>{
   console.log(a,i)
})
  • forEach() is an array method.
  • First parameter gives value.
  • Second parameter gives index.
const arr1 = ['apple','ball','cat']

arr1.forEach((b,c)=>{
   console.log(c,b)
})
  • c → index
  • b → value

Loop on Object

const obj = {
   name:"Reshab",
   age:28,
   1:32
}
    
for(let i in obj){
   console.log(typeof i)
}
  • In for...in, key datatype is always string.
  • In normal for loop, index datatype is number.

Important Notes

  • Objects do not have length property like arrays.
  • for...of loop does not work directly on normal objects.
  • forEach() method works only on arrays.

Check Even or Odd

function checkEvenOdd(a){

    if(typeof a === 'number'){

        if(a % 2 === 0){
            console.log("even")
        }
        else if(a % 2 === 1){
            console.log("odd")
        }
        else{
            console.log("provide number to check")
        }
    }
    else{
        console.log("provide Datatype as number")
    }
}

checkEvenOdd(8)
checkEvenOdd()
checkEvenOdd(9,7,10)
  • typeof is used to check datatype.
  • If datatype is not number, else block will run.
  • Extra arguments are ignored in JavaScript.

        if(typeof i === 'number'){

  • Stored value can be printed later.

Function Overriding

function greet() {
    const a = "hello Everyone"
    return a
}

function greet() {
    const a = 'hii everyone'
    return a
}

console.log(greet())
  • Second function overrides first function.
  • Latest function with same name is executed.

Function Expression

const a = function greet() {

    const a = 'hii everyone'

    return a
}

console.log(a())
  • Function stored inside variable is called function expression.
  • Variable name is used to call function.

Undefined Output Example

const a = function greet() {

    const a = 'hii everyone'

    console.log(a)
}

console.log(a())
  • First console.log prints value.
  • Second console.log prints undefined.
  • Because function does not return anything.

Arrow Function

var great = () => {

    console.log(`hello`)
}

let great = () => {

    console.log(`hello ji`)
}

great()
  • Arrow function is shorter syntax of function.
  • var allows redeclaration.
  • let does not allow redeclaration.
  • This code gives error because great is already declared.

Important Notes

  • Functions can return values using return keyword.
  • Function expression stores function inside variable.
  • Arrow functions are introduced in ES6.
  • Redeclaration rules depend on var, let and const.
Interview Questions

1. Native App vs Progressive Web App

  • Native App → Installed from Play Store/App Store.
  • PWA → Website behaves like mobile app.

2. Difference Between var, let and const

          var a = 10;
          let b = 20;
          const c = 30;
  • var → redeclare and reassign allowed.
  • let → reassign allowed but redeclare not allowed.
  • const → neither redeclare nor reassign allowed.

3. Reassignment vs Redeclaration

          let x = 10;
          x = 20;

          let y = 30;
          let y = 40;
  • Reassignment means changing value.
  • Redeclaration means creating same variable again.

4. prompt() and alert()

  • prompt() returns string value.
  • Use Number() or parseInt() for conversion.

5. Object vs Array

  • Multiple datatype → Object {}
  • Same datatype → Array []

6. What is Dot Notation?

          console.log(obj.name)
  • Used to access object properties.

7. Array is also an Object

          console.log(typeof arr)
  • Array contains key(index) and value(element).
